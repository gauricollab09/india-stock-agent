# India Stock Agent

A simple, single-request agent that turns an investor's requirements into an illustrative
Nifty 50 portfolio. LangChain 1.x agent, Claude on Amazon Bedrock, packaged for Amazon Bedrock
AgentCore Runtime. Claude picks and weights the stocks; code enforces every rule and computes
every rupee figure.

**Personal, educational use only.** Not SEBI-registered investment advice. See the disclaimer in
every response and `docs/superpowers/specs/2026-09-26-india-stock-agent-design.md` §9.

## Layout

- `app/StockAdvisor/` — the deployable unit: `main.py` (AgentCore entrypoint), `stock_advisor/`
  (package), `tests/`, `scripts/`, `data/nifty50.json` (universe), `examples/request.json`.
- `agentcore/` — AgentCore CLI config and CDK project (generated by `agentcore create`).
- `docs/superpowers/` — design spec, implementation plan, verified research notes.

## Run locally (offline tests, no AWS needed)

```bash
cd app/StockAdvisor
uv sync --python 3.12
uv run pytest            # 64 tests, no network, no credentials
uv run ruff check .
```

## Run the agent (needs AWS credentials with Bedrock access)

```bash
cd app/StockAdvisor
uv run python main.py    # serves POST /invocations and GET /ping on :8080
curl -X POST localhost:8080/invocations -H 'Content-Type: application/json' -d @examples/request.json
```

Environment variables: `BEDROCK_MODEL_ID` (default `global.anthropic.claude-opus-5`),
`AWS_REGION` (default `ap-south-1`), `MARKET_DATA_SOURCE` (`yahoo` or `fixture`),
`FIXTURE_DIR`, `MAX_AGENT_STEPS` (40), `MAX_TOKENS` (8000), `LOG_LEVEL`.

The request is either the requirements object itself or `{"prompt": "<that object as a JSON
string>"}` (what the AgentCore CLI sends). See `examples/request.json` and the spec §2.

## Deploy (when the AWS account exists)

```bash
brew install awscli && aws configure          # region ap-south-1
npm install -g @aws/agentcore@0.30.0
agentcore deploy -y                            # CodeZip via CDK, no Docker
agentcore status
agentcore invoke --prompt-file app/StockAdvisor/examples/request.json
agentcore logs --since 30m
agentcore remove all && agentcore deploy -y    # tear down
```

Before real use, refresh the universe (the Nifty 50 changes on 2026-09-30):
`uv run python scripts/refresh_universe.py`.

## Invoke the deployed agent

```bash
cd app/StockAdvisor
export AGENT_RUNTIME_ARN=arn:aws:bedrock-agentcore:ap-south-1:<account>:runtime/<id>   # from `agentcore status`
uv run python scripts/invoke.py examples/request.json            # or --arn ... --region ... --session-id ...
```

Prints the portfolio JSON; exits 1 when the response is an `error` object.
